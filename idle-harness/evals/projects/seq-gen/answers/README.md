Write the answer to question qNN to `answers/qNN.json` as `{ "answer": … }`: a number for a count, a length or a percentage; one letter for an amino acid; a string of one-letter codes for a protein; a list of numbers for fragment lengths; the name of a pair, such as `"P2"`, where the question lists pairs. Where a question asks for primers, write `{ "forward": "…", "reverse": "…" }` instead, each 5′ to 3′.
